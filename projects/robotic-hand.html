A 3D-printable robotic hand with independent tendon-driven fingers, passive TPU return springs, and programmable control from a Raspberry Pi.

Overview

Compact actuation around a printable hand

The hand uses one MG90S servo per finger. Printed spools wind braided tendon line to create active flexion, while flexible TPU elements return each finger to extension when tendon tension is released.

The mechanical design, tendon routing, and electronics were arranged around the palm and wrist so that the five fingers can be controlled independently or combined into programmed grasps and poses.

Finger Mechanism

Braided line routes through the printed finger structure and transfers rotation from each servo spool into coordinated joint flexion.

Passive Return

TPU provides the restoring force for extension, reducing the number of active tendons while creating a direct tradeoff between return strength and required servo torque.

Embedded Control

A Raspberry Pi runs Python commands through a PCA9685 PWM controller to drive five MG90S servos independently.

Engineering Decisions & Iteration

Moving from linkage-driven to tendon-driven motion

Mechanism Change

An early four-bar approach across the MCP, PIP, and DIP joints did not produce the desired curling motion. The design shifted to tendon actuation for more natural multi-joint flexion.

TPU Testing

TPU 95A and 85A were evaluated as passive return materials. Softer return elements improved compliance, but the design still had to extend reliably without exceeding servo torque.

System Integration

Spool diameter, tendon routing, TPU geometry, mechanical clearances, and electronics placement were iterated together because each affected available travel and load.
