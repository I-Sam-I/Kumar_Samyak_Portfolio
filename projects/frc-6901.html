Overview

Competition software built with the full robot

I developed Java robot code for a field-centric swerve drivetrain, subsystem controls, pose estimation, and vision-assisted autonomous routines. As Co-President and Programming Lead, I also coordinated programming with mechanical, electrical, and drive-team needs across a team of more than 50 students.

Technical Breakdown

Robot software and controls

Robot Software

Java and WPILib organized drivetrain and mechanism behavior, operator commands, closed-loop controls, telemetry, and competition-mode state.

Swerve & Localization

Field-centric swerve used gyro heading and wheel feedback for intuitive driving. Odometry tracked robot pose for autonomous motion and repeatable field positioning.

Vision & Autonomous

PhotonVision ran on an Orange Pi and supplied vision measurements. PathPlanner and pose data supported vision-assisted autonomous routines.

Controls & Hardware

PID control, CTRE Phoenix 6 motor APIs, Kraken X60 motors, and the robot's CAN network connected high-level behavior to drivetrain and mechanism hardware.

Driver Integration

Software behavior was tuned around driver input, mechanism timing, sensor feedback, and the constraints found during practice and competition.

Autonomous Integration

Trajectory following, robot pose, mechanism commands, and vision updates were combined into autonomous sequences designed for field execution.

Debugging

Tracing failures across software and hardware

Elevator Encoder Conversion

An elevator began reporting incorrect position values. Reviewing Git history exposed an incorrect conversion constant, which connected the observed sensor behavior to the specific code change.

Pivot Mounting Failure

A pivot motor mounting failure during competition demonstrated that software behavior could not be separated from mechanical loading and mounting constraints. The response required cross-team diagnosis and decisions.

Competition Workflow

Logs, telemetry, code history, controlled tests, and direct coordination with mechanical and electrical members narrowed problems under limited practice and event time.
