Gym Bro

A browser-based workout assistant that uses real-time pose tracking and motion analysis to count exercise repetitions without sending camera data to a server.

Overview

Real-time feedback in the browser

Built with vanilla JavaScript and Vite, Gym Bro uses the webcam through getUserMedia and MediaPipe Tasks Vision's Pose Landmarker to follow a user's movement. The current implementation focuses on side-view bicep curls and performs inference locally in the browser.

Pose Input

The webcam feed is passed to Pose Landmarker, then pose landmarks and the live skeleton overlay are rendered through the Canvas API.

Motion Analysis

The pipeline selects the visible arm, rejects low-confidence landmarks, and calculates the elbow angle from shoulder, elbow, and wrist positions.

Repetition State

Smoothing reduces landmark jitter. A movement state machine counts a repetition only after the arm completes the required extension-to-flexion transition.

Engineering Decisions

Designing for usable movement signals

Local-first Processing

Running pose estimation in the browser keeps the interaction responsive and avoids uploading a live camera stream.

Side-view Geometry

The initial exercise is constrained to a side view so the elbow angle provides a clearer signal and the more visible arm can be selected reliably.

Transition-based Counting

Confidence filtering, smoothing, and explicit movement states reduce false counts from noisy landmarks or small movements near an angle threshold.

Result & Status

Real-time pose analysis runs locally in the browser.
